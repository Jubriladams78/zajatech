Services

Services

Eight service areas, described in plain terms.

IT help desk and device support

Practical help when computers, phones, printers, and accounts stop working.

What this includes

  • Troubleshooting computers, laptops, and mobile devices
  • Printer and peripheral setup and repair
  • Account, password reset, and software issues
  • Clear notes on what was found and fixed

Microsoft 365

Setting up and supporting Microsoft 365 for individuals and teams.

What this includes

  • Email, calendar, and Teams setup
  • User and license management
  • OneDrive and SharePoint file sharing
  • Migration help when moving to Microsoft 365

Networking and Wi-Fi

Reliable home and office networks, planned and documented.

What this includes

  • Wired and wireless network setup and review
  • Wi-Fi coverage and connectivity troubleshooting
  • Router, switch, and firewall configuration
  • Basic network documentation

Cloud and backup services

Cloud accounts and backups that are organized and easy to understand.

What this includes

  • Support for Microsoft Azure and AWS
  • Backup planning and setup
  • Organizing cloud resources and access
  • Documentation of what is set up

Windows and Linux server support

Setup, care, and documentation for Windows and Linux servers.

What this includes

  • Windows Server and Linux server setup and administration
  • User accounts, groups, and permissions
  • Routine system care and updates
  • Documentation of how the server is configured

Identity and access management

Making sure the right people have the right access.

What this includes

  • Active Directory and Microsoft Entra ID
  • User and group management
  • Single sign-on and multi-factor authentication setup
  • Access reviews and cleanup

Security configuration and access controls

Practical settings that reduce everyday risk.

What this includes

  • Sensible security settings for devices and accounts
  • Access controls based on least privilege
  • Guidance on safer everyday practices
  • Documentation of the settings used

Contract IT staffing

IT professionals for larger organizations that need contract help.

What this includes

  • Contract support for projects and ongoing coverage needs
  • Additional IT professionals coordinated as the work requires
  • Scope, timing, and fees agreed before work begins

Who ZajaTech serves

  • Households and individuals
  • Small businesses
  • Larger organizations, through contract work

Service area

Remote support is available worldwide. On-site support is available in the Palatine and Northwest suburbs of Illinois.

How scope, timing, and fees are agreed

Scope, timing, and fees are discussed and agreed before work begins.

How to request support

  1. Get in touch. Use the details on the Contact page and describe what is needed.
  2. The request is reviewed. ZajaTech checks whether the request fits the services above.
  3. Details are agreed. Scope, timing, and fees are discussed and agreed before work begins.

Please do not send sensitive data

In a first message, describe the problem only. Never include passwords, account numbers, or private files.
